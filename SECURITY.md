# Security Policy

## Supported Versions

We recommend keeping your local forks, dependencies, and environment up to date to ensure all security patches are applied.

| Version / Branch | Supported          |
| ---------------- | ------------------ |
| `main` / `master`| :white_check_mark: |

## Reporting a Vulnerability

We take the security of this repository and website seriously. If you discover a security vulnerability, please report it responsibly rather than opening a public issue.

### How to Report

1. **GitHub Private Vulnerability Reporting**: If enabled on this repository, please navigate to the **Security** tab of the repository and submit a private security advisory report.
2. **Direct Contact**: Alternatively, you can contact the repository maintainers via the contact details specified in the maintainer profile or `_config.yml`.

Please include the following details in your report:
- A description of the vulnerability and its potential impact.
- Detailed step-by-step instructions or proof-of-concept (PoC) script to reproduce the issue.
- Any suggested mitigations or patches, if available.

### Disclosure Policy

- We will acknowledge receipt of your report promptly.
- We will evaluate the report and work on a fix as quickly as possible.
- Please allow reasonable time to address and patch the issue before making any public disclosures.

Thank you for helping keep this project and community safe!
